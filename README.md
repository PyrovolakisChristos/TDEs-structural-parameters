# TDEs-structural-parameters

This repository contains the TDE structural-parameter data files.

## Data files

- [r_band.csv](data/r_band.csv)
- [g_band.csv](data/g_band.csv)
- [Excluded_TDEs.csv](data/Excluded_TDEs.csv)

## Interactive catalog

Open [catalog.html](catalog.html) to browse the r-band and g-band tables with search and excluded-TDE warnings.

Open either file directly in a browser to view the available data.
